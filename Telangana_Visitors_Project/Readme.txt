Telangana Tourism Dashboard

The presented dashboard offers a comprehensive snapshot of Telangana's tourism industry, highlighting the top-rated tourist spots, lodgings, and recreational pursuits within the region. The statistics are sourced from Codebasics as a component of their challenge, supplemented with supplementary resources obtained for the same purpose.

Process : Sql for Queries and Power Bi for Data Visualization.

Data Collection and Preparation : The data was then cleaned, transformed by powerquery and loaded into Power BI for analysis and visualization.

Insights & Suggestions : Check 'Insights.txt' file.
